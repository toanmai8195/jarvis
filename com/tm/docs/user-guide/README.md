# Hướng dẫn sử dụng

- [Người dùng (client)](client.md) — đặt vé xe khách, tàu điện và quản lý ví
- [Quản trị (admin)](admin.md) — vận hành tuyến, lịch chạy, giá vé và theo dõi thống kê

## Thuật ngữ

| Thuật ngữ | Ý nghĩa |
|---|---|
| **Tuyến** (route) | Hành trình cố định gồm nhiều trạm/bến theo thứ tự, ví dụ Hà Nội → Hải Phòng |
| **Trạm / bến** (station) | Điểm đón/trả khách |
| **Phương tiện** (vehicle) | Một xe khách hoặc một đoàn tàu, gắn với một sơ đồ ghế |
| **Sơ đồ ghế** (seat layout) | Bố trí ghế/giường và hạng ghế của phương tiện |
| **Slot / chuyến** (trip) | Một lần chạy cụ thể của tuyến tại một thời điểm, trên một phương tiện |
| **Giữ chỗ** (hold) | Ghế được tạm khoá cho bạn trong thời gian ngắn trước khi thanh toán |
| **Ví** (wallet) | Tài khoản tiền nội bộ dùng để thanh toán vé |
